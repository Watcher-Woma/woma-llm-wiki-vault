## 定义

零样本提示（Zero-Shot Prompting）是指在不提供任何示例的情况下，直接向大语言模型提出问题或指令，利用模型从预训练中获得的知识来生成响应。这是与少样本提示（Few-Shot）相对的概念。

## 工作原理

现代大型语言模型在预训练过程中已经学习了海量的语言模式、概念和关系。零样本提示利用这一能力，通过精心设计的指令直接触发模型的内在知识。

```
用户 → "将以下句子分类为积极或消极：今天天气真好"
模型 → "积极"
```

## 适用场景

### 适合零样本的任务
- **简单分类**：情感分析、主题识别
- **基础翻译**：常见语言对
- **格式转换**：JSON ↔ Markdown ↔ CSV
- **通用知识问答**：事实性问题
- **标准格式生成**：邮件、请假条、简历摘要

### 不适合零样本的任务
- **复杂推理**：多步骤逻辑问题 → 使用 [[Chain_of_Thought|CoT]]
- **专业领域**：需要领域知识 → 使用 [[Few_Shot_Prompting|Few-Shot]]
- **精确格式**：严格结构要求 → 提供示例
- **风格匹配**：需要模仿特定文风 → 提供样本

## 最佳实践

### 1. 使用清晰的动作词
| ❌ 模糊 | ✅ 清晰 |
|--------|--------|
| "处理这个" | "提取并总结" |
| "看看这个对不对" | "检查语法错误并纠正" |
| "回答问题" | "用一句话回答，并标注信息来源" |

### 2. 包含必要上下文
```
❌ "解释量子计算"
✅ "用 200 字向计算机专业大一学生解释量子计算，
    避免数学公式，重点说明量子优势"
```

### 3. 指定输出格式
```
"列出 5 个要点，每点不超过 15 字"
"以表格形式返回，包含列：名称、年龄、职位"
```

### 4. 设置约束边界
```
"不要超过 500 字"
"只返回代码，不包含解释"
"用中文回答"
```

## 进阶技巧

### 角色 + 零样本
即使没有示例，指定角色也能显著提升效果：

```
"作为有 20 年经验的法律顾问，用专业但易懂的语言，
  解释这份合同中的三个主要风险点"
```

### 链式指令
将复杂任务拆分为多个零样本指令：

```
1. "先阅读以下文本，识别核心观点"
2. "针对每个观点，提供一个支持论据"
3. "最后用一句话总结全文"
```

## 与其他技术对比

| 技术 | 示例数量 | 适用复杂度 | Token 消耗 |
|------|----------|------------|------------|
| **Zero-Shot** | 0 | 低-中 | 最低 |
| **Few-Shot** | 1-10 | 中-高 | 中等 |
| **Chain-of-Thought** | 0-3 | 高 | 中-高 |
| **Tree of Thoughts** | 多路径 | 极高 | 高 |
