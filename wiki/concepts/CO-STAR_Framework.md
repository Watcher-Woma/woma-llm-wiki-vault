## 定义

CO-STAR 框架是一种专为内容创作设计的提示工程方法，包含六个核心要素：**C**ontext（上下文）、**O**bjective（目标）、**S**tyle（风格）、**T**one（语气）、**A**udience（受众）、**R**esponse（响应格式）。

该框架由 Shane King（新加坡数据科学家）提出，特别适合需要高质量输出的内容创作场景。

## 框架六要素

### 1. Context（上下文）
提供任务的背景信息，帮助 AI 理解场景。

```
示例：
"我们是一家 B2B SaaS 公司，刚刚完成 B 轮融资，
估值达到 1 亿美元，正在扩大市场份额"
```

### 2. Objective（目标）
明确你希望 AI 完成的具体任务。

```
示例：
"撰写一篇 800 字的公司新闻稿，宣布融资消息"
```

### 3. Style（风格）
指定内容应采用的语言风格或写作风格。

| 风格类型 | 适用场景 | 示例 |
|----------|----------|------|
| **专业权威** | 行业分析、白皮书 | "模仿麦肯锡报告风格" |
| **轻松友好** | 社交媒体、博客 | "像朋友间的对话" |
| **新闻客观** | 新闻稿、公告 | "遵循倒金字塔结构" |
| **学术严谨** | 论文、研究 | "APA 格式，科学语言" |

### 4. Tone（语气）
定义内容的情感基调和表达方式。

| 语气 | 说明 | 示例词 |
|------|------|--------|
| **热情洋溢** | 高能量、正面 | "激动人心"、"突破性" |
| **专业冷静** | 理性、不带感情色彩 | "数据显示"、"研究表明" |
| **温暖亲切** | 人情味、亲和力 | "我们理解您"、"贴心服务" |
| **紧迫感** | 促进行动 | "立即行动"、"限时机会" |

### 5. Audience（受众）
精确描述目标读者群体。

```
❌ "写给营销人员"
✅ "写给 30-45 岁的 B2B 企业营销总监，
   他们关注 ROI 和数字化转型，对技术术语有一定了解"
```

### 6. Response（响应格式）
明确期望的输出结构。

```
示例：
"文章结构：标题 → 导语（100字）→ 
3个要点（各200字）→ 结论+CTA（100字）"
```

## 完整模板

```markdown
## Context（背景）
[提供任务所需的背景信息]

## Objective（目标）
[明确你要完成的具体任务]

## Style（风格）
[指定内容风格或参考风格]

## Tone（语气）
[指定情感基调和表达方式]

## Audience（受众）
[精确描述目标读者]

## Response（格式）
[期望的输出结构和长度]
```

## 使用示例

### 示例 1：LinkedIn 帖子
```markdown
## Context
我们是一家 50 人规模的 AI 创业公司，刚刚发布了一款
革命性的代码审查工具，获得 TechCrunch 报道

## Objective
撰写一条 LinkedIn 帖子，宣布产品发布

## Style
专业但有活力，像科技行业领袖的口吻

## Tone
自信、略带兴奋，但不夸张

## Audience
软件工程师、技术总监、CTO、科技投资人

## Response
- 开头：吸引注意力的钩子（1-2 句）
- 正文：产品核心价值（3-4 点）
- 结尾：CTA（试用链接 + 邀请反馈）
- 长度：150-250 字
- 包含 2-3 个相关 hashtags
```

### 示例 2：产品文案
```markdown
## Context
我们是面向独立开发者的项目管理工具，
月费 9 美元，刚完成 UX 大改版

## Objective
撰写产品 landing page 的主标题和副标题

## Style
简洁、直击痛点，类似 Linear/Notion 的文案风格

## Tone
自信、专业，但不失亲和力

## Audience
有个人项目或小团队的独立开发者，
年收入在 5-50 万之间

## Response
- 主标题：不超过 8 个字
- 副标题：1 句话，不超过 15 个字
- 需要 3 个变体供选择
```

## 框架对比

| 框架 | 复杂度 | 核心优势 | 最佳场景 |
|------|--------|----------|----------|
| **CO-STAR** | 中高 | 全面覆盖创作要素 | 营销文案、正式内容 |
| **APE** | 低 | 简洁行动导向 | 快速任务 |
| **CRAFT** | 中 | 角色扮演能力强 | 专业咨询 |
| **5C** | 低 | Token 高效 | 极简场景 |

## 最佳实践

1. **Context 要具体**：提供足够的背景，但避免无关信息
2. **Objective 单一性**：一个 CO-STAR 提示专注一个任务
3. **Style 和 Tone 区分**：Style 是"怎么写"，Tone 是"什么感觉"
4. **Audience 画像化**：用人口统计+心理特征描述受众
5. **Response 结构化**：给出明确的格式、长度、变体数量要求
